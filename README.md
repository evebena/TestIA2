# Casse-brique des 4 saisons

Un jeu de casse-brique en HTML, CSS et JavaScript vanilla, avec une direction artistique lumineuse autour du printemps, de l'été, de l'automne et de l'hiver.

## Lancer le jeu

Ouvrez `index.html` dans un navigateur moderne, ou servez le dossier avec :

```bash
python3 -m http.server 8000
```

Puis rendez-vous sur <http://localhost:8000>.

## Contrôles

- Souris ou tactile : déplacer la raquette.
- Flèches gauche/droite : déplacer la raquette.
- Espace : lancer la balle.
- Boutons à l'écran : pause, nouvelle partie et changement de saison.
